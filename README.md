# Fu Jen imMBA website

A redesigned public website for Fu Jen Catholic University’s **MBA Program in International Management (imMBA)**.

It keeps the original programme’s main sections—about, admissions, curriculum, faculty, student guide, graduation, dual degree, exchange, news, gallery, contact, and related links—with a cleaner bilingual (中文 / English) layout.

Content is based on the official site:
https://www.management.fju.edu.tw/subweb/immba/

Admissions dates, tuition, and regulations should always be confirmed against College of Management notices.

## Preview

This is a static site (HTML, CSS, JavaScript). Open `index.html` in a browser, or from this folder run a local server if you have one available.

## Language

Use **中 / EN** in the header. The choice is stored in the browser and kept in the page URL as `?lang=zh` or `?lang=en`.
